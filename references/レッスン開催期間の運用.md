# レッスンの開始月・最終開催月（2026-09 追加）

時間割のレッスンに「いつから」「いつまで」を持たせられるようになりました。
これで**過去の月をそのまま残したまま、今月から新しいクラスに差し替える**ことができます。

## なぜ必要だったか

名簿（`schedule`）も時間割（`timeSchedule`）も**全ての月で共通**の1つのデータです。
そのため従来は、新しいクラスを1つ追加すると、**去年の出席名簿にもそのクラスが0名で出て**しまいました。
逆に古いクラスを消すと、過去の記録まで見えなくなる恐れがありました。

開始月・最終開催月を入れると、その期間だけに出るようになります。過去の月は一切変わりません。

## 使い方

時間割の画面で、レッスンを追加または既存のレッスンをクリックすると、入力欄に2つ増えています。

| 欄 | 意味 | 空欄にすると |
|---|---|---|
| **開始月** | この月から各画面に出ます | 全ての月に出ます（従来どおり） |
| **最終開催月** | **この月まで**開催。翌月から消えます | ずっと続きます |

- 新しくレッスンを追加するときは、**開始月に「表示している月」が自動で入ります**。そのままで構いません。
- 「最終開催月 2026-08」と入れたクラスは、**8月までは今までどおり表示され、9月から消えます**。

### クラスを差し替えるとき

1. 古いクラスをクリック → **最終開催月**に「その月まで開催する月」を入れる → 保存
2. 新しいクラスを追加 → **開始月**にその翌月を入れる → 保存

これだけです。生徒ひとりずつに退会月を入れる必要はありません。
最終開催月を過ぎたクラスは、**名簿に生徒が残っていても**自動的に隠れます。

### 生徒はどうなるか

- 名簿の生徒データも、過去の出席記録も**消えません**。過去の月を開けばそのまま見えます。
- 生徒を新しいクラスへ移す場合は、新クラスの名簿に「生徒を追加」してください。
- 古いクラスの名簿から生徒を消す必要はありません（クラスごと隠れるため）。

## 反映される画面

開始月・最終開催月は次のすべてに効きます。

| 画面 | 効き方 |
|---|---|
| 週間時間割 | 表示中の月に開催されるレッスンだけ |
| 月間スケジュール | **その日が属する月**で判定（月をまたぐ週も正しく出ます） |
| 出席名簿 | 期間外のクラスは非表示 |
| HOME のレッスン一覧 | 同上 |

**顧客詳細の「受講中クラス」は対象外**です。ここは名簿の在籍そのものを見るため、
生徒を退会扱いにするまで表示が残ります。クラスの終了と、その生徒が辞めたかどうかは別だからです。

## 注意

- **休講設定はクラス名と会場で紐づいています**（`クラス名 講師名__会場`）。
  クラス名を変えて登録し直すと、前のクラスに入れた休講設定は復活しません。新しい名前で入れ直してください。
- 既に登録済みのレッスンは、開始月も最終開催月も空欄です。これまでどおり全ての月に出ます。触る必要はありません。
